# Applied Sciences & Tech — coverage map

This domain is built for breadth against established knowledge-classification
systems. Each discipline is tagged with where it sits in those schemes so we can
spot gaps in future rounds. (This file starts with `_` / is not `.json`, so the
engine ignores it.)

Reference systems used:
- **DDC** — Dewey Decimal, 600s (Technology / Applied Sciences)
- **LCC** — Library of Congress, T schedule (Technology) + R (Medicine), S (Agriculture)
- **OECD** — Frascati Manual, Fields of Science "Engineering & Technology"
- **ACM CCS** — ACM Computing Classification System (computing sub-tree)
